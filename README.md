# Tosder Communities

Cambodia travel community platform — discover destinations, create reusable itineraries, and share travel templates.

## Status

Pre-implementation. The product flow is documented in [`cambodia_travel_platform_flow.pdf`](./cambodia_travel_platform_flow.pdf), and the MVP work is tracked in [Issues](https://github.com/srosthai/tosder/issues) and [Milestones](https://github.com/srosthai/tosder/milestones).

## Stack

- Astro + TypeScript
- Nitro API
- Supabase (PostgreSQL, Auth, Storage)
- Prisma ORM
- Leaflet + PostGIS

## Development

The app is not scaffolded yet. Setup instructions will be added with the initial scaffold.
